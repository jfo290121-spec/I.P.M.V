# Igreja Evangélica Comunidade - I.P.M.V

## 📱 Aplicativo Comunitário

Aplicativo web responsivo para gerenciamento de informações e interações da comunidade religiosa.

### ✨ Funcionalidades

- **🏠 Início** - Versículo do dia, palavra do pastor e boas-vindas
- **📅 Agenda** - Horários de cultos e próximos eventos
- **🙏 Oração** - Formulário para pedidos de oração da comunidade
- **💝 Dízimos** - Informações sobre contribuições via PIX

### 🚀 Características Técnicas

- ✅ Design responsivo (mobile-first)
- ✅ Interface intuitiva com abas de navegação
- ✅ Formulário de pedidos de oração
- ✅ Cópia de chave PIX com um clique
- ✅ Suporte a navegação por gesto (swipe)
- ✅ Persistência de dados (localStorage)
- ✅ Animações suaves e feedback visual
- ✅ Otimizado para performance

### 📁 Estrutura de Arquivos

```
.
├── index.html          # Arquivo principal
├── css/
│   └── styles.css     # Estilos do aplicativo
├── js/

```

### 🔧 Como Usar

1. Clone o repositório ou acesse através do GitHub Pages
2. Abra `index.html` em seu navegador
3. Navegue entre as abas usando os botões inferiores
4. Pressione e arraste (swipe) para navegar entre abas no mobile
